## My Study Assistant Design

My Study Assistant has three tools:

### 1. Calculator
Purpose:
Perform mathematical calculations.

Example:
User: What is 25 * 10?
Assistant: Use Calculator
Result: 250

### 2. Python Tool
Purpose:
Help the user with Python programming.

Example:
User: Explain Python loops.
Assistant: Use Python Tool

### 3. File Reader
Purpose:
Read and summarize study files.

Example:
User: Read my notes.txt file.
Assistant: Use File Reader

## Tool Selection

The assistant should select a tool based on the user's request.

Math question → Calculator
Python question → Python Tool
File-related question → File Reader
